# 📸 Guide : Comment ajouter des captures d'écran au README

## 🎯 Étapes simples (5 minutes)

### 1️⃣ Ouvrir les pages web

Dans l'Explorateur Windows, allez dans :
```
C:\Users\ElKansouli Ouiam\Desktop\spring-hibernate-demo\demo-static\
```

### 2️⃣ Prendre les 4 captures d'écran

#### Capture 1 : Page d'accueil

1. **Double-cliquez** sur `index.html`
2. **Appuyez** sur `Windows + Shift + S`
3. **Sélectionnez** toute la page
4. **Ouvrez Paint** (`Windows + R` → tapez `mspaint` → Entrée)
5. **Collez** (`Ctrl + V`)
6. **Enregistrez** : Fichier → Enregistrer sous
   - Nom : `home.png`
   - Emplacement : `C:\Users\ElKansouli Ouiam\Desktop\spring-hibernate-demo\screenshots\`

#### Capture 2 : Liste des produits

1. **Cliquez** sur "Voir les Produits" OU ouvrez `products.html`
2. **Appuyez** sur `Windows + Shift + S`
3. **Sélectionnez** toute la page
4. **Collez** dans Paint
5. **Enregistrez** comme `products.png` dans le dossier `screenshots/`

#### Capture 3 : Liste des catégories

1. **Ouvrez** `categories.html`
2. **Appuyez** sur `Windows + Shift + S`
3. **Sélectionnez** toute la page
4. **Collez** dans Paint
5. **Enregistrez** comme `categories.png` dans `screenshots/`

#### Capture 4 : Formulaire

1. **Ouvrez** `product-form.html`
2. **Appuyez** sur `Windows + Shift + S`
3. **Sélectionnez** toute la page
4. **Collez** dans Paint
5. **Enregistrez** comme `product-form.png` dans `screenshots/`

---

## 3️⃣ Pousser les images vers GitHub

```bash
git add screenshots/
git commit -m "docs: ajout des captures d'écran de l'interface"
git push origin main
```

---

## ✅ C'est tout !

Les images apparaîtront automatiquement dans le README sur GitHub ! 🎉

---

## 🎨 Conseils pour de belles captures

- ✅ Mettez votre navigateur **en plein écran** (F11)
- ✅ **Zoomez à 100%** (Ctrl + 0)
- ✅ Capturez **toute la page** visible
- ✅ Utilisez un **fond clair** dans votre navigateur

---

## 🔄 Alternative : Utiliser l'outil Capture Windows

1. **Ouvrez** Outil Capture (Recherche Windows : "Outil Capture")
2. **Nouveau** → Sélectionnez la zone
3. **Enregistrez** dans `screenshots/` avec le bon nom

---

## 📱 Format recommandé

- **Format :** PNG (meilleure qualité)
- **Résolution :** 1920x1080 ou moins
- **Taille :** < 500 KB par image
