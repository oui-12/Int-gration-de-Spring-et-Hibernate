# 📸 Screenshots - Instructions

## Comment ajouter des captures d'écran au README

### 1️⃣ Prendre des captures d'écran

Ouvrez les pages dans `demo-static/` et prenez des captures :

1. **Ouvrir** `demo-static/index.html` dans votre navigateur
2. **Appuyez sur** `Windows + Shift + S` (Outil Capture Windows)
3. **Sélectionnez** la zone à capturer
4. **Enregistrez** l'image dans ce dossier (`screenshots/`)

### 2️⃣ Noms des fichiers recommandés

Prenez ces 4 captures d'écran :

- `home.png` - Page d'accueil (index.html)
- `products.png` - Liste des produits (products.html)
- `categories.png` - Liste des catégories (categories.html)
- `product-form.png` - Formulaire produit (product-form.html)

### 3️⃣ Les images seront automatiquement affichées dans le README

Une fois les captures placées ici, elles apparaîtront dans le README principal !

---

## ✨ Alternative rapide

Vous pouvez aussi utiliser ces outils :

- **Outil Capture Windows** : `Windows + Shift + S`
- **Snipping Tool** : Recherchez "Outil Capture" dans Windows
- **Screenshot** : `Print Screen` puis collez dans Paint
